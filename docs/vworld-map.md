# 브이월드 지도 설정

`/map`은 국토교통부 공간정보 오픈플랫폼(브이월드)의 배경지도와 주소 좌표 변환 API를 사용한다.

`.env.local`과 배포 환경에 다음을 설정한다. 실제 키는 커밋하지 않는다.

```dotenv
NEXT_PUBLIC_VWORLD_API_KEY=발급받은_인증키
NEXT_PUBLIC_VWORLD_DOMAIN=http://localhost:3000
```

브이월드에서 인증키를 발급하고 실제 접속 도메인을 등록한다. 배포 시 서비스 도메인을 사용한다.
`NEXT_PUBLIC_*`는 브라우저 빌드에 포함되므로 변경 후 서버 재시작 또는 재빌드가 필요하다.
브라우저 배경지도 호출용 키이므로 비밀 키로 취급하는 구조가 아니다. 도메인 제한을 사용한다.

- 지도 타일: `https://api.vworld.kr/req/wmts/1.0.0/{key}/Base/{z}/{y}/{x}.png`
- 좌표 변환: `GET /api/map/geocode?address=...` → 브이월드 `getcoord`, EPSG:4326
- 도로명 주소를 먼저 조회하고 NOT_FOUND일 때 지번 조회로 재시도한다.
- 실제 공간 주소를 조회하며, 권역 중심점을 공간의 실제 위치처럼 표시하지 않는다.
- API 실패 및 주소 미확인 공간도 목록과 상세 링크는 유지한다.
- 인증키가 없으면 지도 준비 안내를 표시한다. 실제 타일과 좌표 변환 검증에는 유효한 키가 필요하다.

공식 참고: https://github.com/V-world/V-world_API_sample/tree/master/브이월드_교육/2026년_브이월드_교육

## 통합 검색 복수 선택

현재 공간 API는 지역과 카테고리를 각 1개씩 받는다. 단일 선택은 기존 요청을 사용한다.
복수 선택은 서버에서 지원하는 다른 조건과 단일 값을 먼저 적용하고,
그 결과의 전체 페이지를 최대 4개씩 병렬로 조회한 뒤 필터링한다.
지역 안에서는 OR, 카테고리 안에서는 OR, 두 조건 사이에서는 AND다.
서버 순서를 유지하며 최종 결과 수와 페이지 수를 다시 계산한다.
데이터가 많아지면 서버에 배열 조건 검색을 추가하는 편이 효율적이다.
팝업도 필터 적용 시 전체 페이지를 조회해 기존 한 페이지 제한으로 누락되는 결과를 없앤다.
